# 🚀 Django Expense Tracker

A beginner-friendly Expense Tracker Dashboard built using Django.

## 🔥 Features

- Add Transaction
- Update Transaction
- Delete Transaction
- Search Transactions
- Dashboard Summary
- Income & Expense Tracking
- Pie Chart Analytics
- Admin Panel
- Responsive Bootstrap UI

## 🛠️ Tech Stack

- Python
- Django
- SQLite
- Bootstrap 5
- Chart.js
